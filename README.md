## About

I spent years around RF systems, spectrum analyzers, and signal generators before I wrote
production code — and lab work is where I learned the lesson that still drives most of what
I build: **if a person is doing it twice, it should be doing itself.**

That's the throughline. Test benches that run themselves. Measurement pipelines that don't
need a human babysitting a GPIB cable. Interfaces that make instrument data readable by
someone who isn't the person who took the measurement.

```text
Hardware → Instrument control → Data pipelines → Interfaces people actually use
```

- 🎓 &nbsp;CS student, building toward the intersection of embedded systems and software
- 📡 &nbsp;RF and lab automation work on the side
- 🛠️ &nbsp;Most at home in Python for the backend, React + TypeScript for the front
- 🧪 &nbsp;Currently deepening: real-time data handling and clean API design
